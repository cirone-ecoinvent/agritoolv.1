# Decision log

Log of the decisions of the AgriTool project, newest last: date, who decided, the decision, the
reason and the rejected alternatives. The rules and working instructions that follow from these
decisions are written only in `CLAUDE.md` (section in brackets); this file records when and why
they were decided. This file, the git history, the pull requests and the review columns of the
data tables (`status`, `reviewed_by`) are the authoritative record.
FC = Francesco Cirone (Sector Manager Agriculture, ecoinvent).
